# BusChord brand assets

Provided by the project owner as `buschord-house-icon-pack.zip` (house/building
variant). Supersedes the earlier letter-mark pack.

| File | Use |
|---|---|
| `buschord-house-icon.ico` | Windows executable icon (`ApplicationIcon`) and embedded window icon |
| `buschord-house-icon-256.png` | Window/taskbar icon and start-surface mark |
| `buschord-house-icon-1024.png` | Source size for store/readme artwork |
| `buschord-house-icon.svg` | Vector source of the app icon |
| `buschord-house-preview.png` | Size preview sheet from the pack |

The files are project artwork, not third-party Material Symbols. The UI icon set
in `Assets/Icons.axaml` is separate (Material Symbols, Apache-2.0; see
`Assets/ICONS.md`).
