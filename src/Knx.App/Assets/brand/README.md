# BusChord brand assets

Provided by the project owner as `buschord-icon-pack.zip`.

| File | Use |
|---|---|
| `buschord-icon.ico` | Windows executable icon (`ApplicationIcon`) |
| `buschord-icon-256.png` | Window and taskbar icon, start-surface mark |
| `buschord-icon-1024.png` | Source size for store/readme artwork |
| `buschord-icon.svg` | Vector source of the app icon |
| `buschord-mark-transparent.svg` | Vector mark for light/dark surfaces (not rasterised yet) |

The files are project artwork, not third-party Material Symbols. The UI icon set
in `Assets/Icons.axaml` is separate (Material Symbols, Apache-2.0; see
`Assets/ICONS.md`).
