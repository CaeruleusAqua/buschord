# BusChord brand assets

Provided by the project owner as `buschord-house-transparent-tile-pack.zip`
(house/building motif, rounded tile with transparent outer area). Supersedes
the opaque-corner tile pack and the earlier letter mark.

| File | Use |
|---|---|
| `buschord-house-transparent-tile.ico` | Windows executable icon (`ApplicationIcon`) |
| `buschord-house-transparent-tile-256.png` | Window and taskbar icon, start-surface mark |
| `buschord-house-transparent-tile-1024.png` | Source size for store/readme artwork |
| `buschord-house-transparent-tile.svg` | Vector source of the app icon |
| `buschord-house-transparent-tile-preview.png` | Size preview sheet from the pack |
| `buschord-mark.png` | Borderless artwork for the splash screen |

The files are project artwork, not third-party Material Symbols. The UI icon set
in `Assets/Icons.axaml` is separate (Material Symbols, Apache-2.0; see
`Assets/ICONS.md`).
