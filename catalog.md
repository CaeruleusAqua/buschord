# Product catalogues

BusChord imports local product catalogue files into its catalogue library.
Select a supported product and application before inserting a device.
Project object links are managed separately.

Imported files are kept in the local catalogue directory. A broken catalogue
does not prevent other library entries from being loaded. Unsupported plug-ins
are not executed; a signature file's presence does not establish its validity.

See [README](README.md) for the build and the catalogue source in
`src/Knx.Core/Catalog` for the API available in this version.
